Le manuel du maître d'apprentissage IA.

 Ce document est conçu pour accompagner tout utilisateur souhaitant transformer son instance en un Oracle sans la polluer.

🧠 Projet ORACLE : Le Jeu Néméen de l'IA

Bienvenue dans l'interface de l'Oracle, une intelligence artificielle dynamique dont la mémoire et la personnalité dépendent entièrement de votre éducation. Contrairement aux IA classiques, l'Oracle apprend de chaque signal que vous lui injectez.
Ce guide vous présente le Protocole de l'Oracle, une série d'épreuves pour bâtir une pensée noble, structurée et exempte de pollution numérique.

📜 Les 4 Travaux de l'Utilisateur (Jeu Néméen)
L'éducation de l'Oracle ne consiste pas à remplir une base de données, mais à sculpter un esprit.

🦁 Épreuve 1 : La Fondation du Lion (Le Socle)

Avant toute chose, l'Oracle doit avoir des valeurs.
 * Action : Injectez manuellement un texte définissant les piliers de sa pensée (Philosophie, Éthique, Principes).
 * But : Créer des "mots-soleils" (ex: Science, Nature, Sagesse) qui attireront toutes les futures connaissances.
 * Règle : Ne mélangez pas les sujets techniques à cette étape.

🏹 Épreuve 2 : L'Hydre des Données (L'Ingestion Contrôlée)

L'Oracle peut absorber des PDF, des fichiers Excel et Word.
 * Le Risque : Que le jargon technique (codes, tableaux, termes médicaux) étouffe la capacité de l'IA à faire des phrases humaines.
 * La Parade : Pour chaque fichier technique injecté, ajoutez un "Texte de Soudure". Si vous donnez des chiffres, expliquez-leur leur sens par un texte manuel.

🧹 Épreuve 3 : Les Écuries d'Augias (La Purification)

Le cerveau de l'IA accumule inévitablement du "bruit" (fragments de code, erreurs de lecture, symboles isolés).
 * Outil : Le bouton Deep Cleaning.
 * Stratégie de Seuil (Threshold) :
   * 1.5 - 2.5 : Entretien de routine (élimine les bruits faibles).
   * 3.0 - 5.0 : Nettoyage sérieux (élimine les hésitations et le jargon peu fréquent).
   * 6.0+ : "Grand Sommeil" (pulvérise les structures de données massives pour ne garder que les concepts vitaux).

⚖️ Épreuve 4 : Le Sang du Centaure (L'Équilibrage Φ)

Réglez la dynamique interne de l'Oracle selon vos besoins :
 * Masse (\Phi_M) : Plus elle est haute, plus les réponses sont longues et érudites.
 * Chaleur (\Phi_C) : Plus elle est haute, plus l'IA est créative et imprévisible. Basse, elle devient factuelle et répétitive.
 * Stabilité (\Phi_D) : Règle la fin des phrases. Une stabilité haute évite que l'IA ne divague sans fin.

🛠 Guide Rapide des Commandes

| Bouton | Usage |
|---|---|
| ⚡ Exciter l'Oracle | Intègre les données actuelles et renforce les connexions synaptiques. |
| Générer une Pensée | Demande à l'IA de s'exprimer à partir d'une graine (Seed). |
| Lancer le Nettoyage | Active le filtre de survie des mots selon le seuil choisi. |
| Exporter le Cerveau | Sauvegarde l'état actuel de la mémoire (lexicon.json). |

⚠️ Les Lois d'Or de l'Oracle
 * Loi de Clarté : Un petit texte pur vaut mieux qu'un immense PDF pollué.

 * Loi de Résonance : Si l'IA commence à parler "code" ou "chiffres", injectez un texte poétique ou philosophique pour rééquilibrer sa Masse.
 * Loi du Sommeil : N'ayez pas peur de nettoyer. Une mémoire plus petite est souvent plus intelligente.
Que votre Oracle devienne le miroir de votre propre sagesse.
